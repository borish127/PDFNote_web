Help & User Guide

Overview

PDFNote is a client-side web application designed to act as a synchronized PDF viewer and page-by-page Markdown notebook. Your text notes, drawings, and markups are automatically linked to their respective pages.

Loading & Saving Documents

  • Open PDF: Loads a PDF file for viewing and drawing.
  • Open Bundle (.pdfmd / .zip): Restores a saved workspace. This loads the original PDF file, all of your page-by-page markdown notes, and drawing layers.
  • Link Folder: Connects to a local directory on your device using the File System Access API. Enabling this folder sync allows the app to automatically write {pdf_name}_notes.json, {pdf_name}_notes.md, and individual assets directly to your disk while you work.
  • Save: Exports your workspace as a .pdfmd zipped file containing notes, images, drawings, and the PDF.

Toolbar Control Reference

  • picture_as_pdf Open PDF: Load a PDF file.
  • folder_open Open Bundle: Load a saved workspace package.
  • sync Link Folder: Sync directly to a local device folder.
  • save Save: Save notes, drawings, and PDF to a bundle package.
  • navigate_before / navigate_next Page Navigation: Turn pages (Keyboard Arrow keys Left/Right also navigate pages when not typing).
  • zoom_out / zoom_in Zoom Controls: Change zoom scale or select fitting behaviors.
  • near_me Cursor Tool: Standard selection tool. Select text directly in the PDF.
  • border_color Highlight Tool: Drag to highlight content (or select text first, then click Highlight).
  • format_underlined Underline Tool: Drag to underline content (or select text first, then click Underline).
  • gesture Draw Tool: Freehand drawing tool for canvas overlay annotations.
  • title Text Tool: Add floating text boxes anywhere on the PDF.
  • signature Signature Tool: Draw, upload, or paste a signature image and click to place it on the page.
  • ink_eraser Eraser Tool: Click or drag over individual annotations to erase them.

Markdown Notebook Editor

  • Take markdown notes for the active page on the right workspace panel.
  • Toggle Edit/Read Mode: Toggle between Markdown notes editing and viewing modes using the floating action button (FAB) or the keyboard shortcut Ctrl + E (or Cmd + E on Mac).
  • Use format accelerators (Link, Image, Mermaid diagrams) in the markdown bar to quickly write rich notes.
  • Images and diagrams are click-to-expand. Clicking them inside notes view mode opens a full-screen blurred lightbox.

Auto-Save & Cache Recovery

  • Typing or drawing automatically saves data to an IndexedDB background cache every 3 seconds.
  • If a browser crash occurs, the app prompts you to restore your exact unsaved session when you reload.

Headings

Use 1 to 6 # symbols followed by a space to create section headings:

# Heading 1
## Heading 2
### Heading 3
#### Heading 4

Text Formatting

  • *italic* or _italic_ → italic
  • **bold** or __bold__ → bold
  • ***bold italic*** → bold italic
  • `inline code` → inline code
  • End a line with two spaces or use <br> for a manual line break.

Lists

Create unordered, ordered, or nested lists (indent nested items by 2–4 spaces):

- Unordered item (* or + also work)
  - Nested item
- Another item

1. First step
2. Second step
   1. Sub-step

Links & Images

  • Links: [Link label](https://example.com) or [With title](https://example.com "Hover title") (http:, https:, mailto:, and #anchor links are supported).
  • External images: ![Alt text](https://example.com/photo.png)
  • Local pasted/uploaded images: Paste (Ctrl+V), drag-and-drop an image onto the editor, or click the Image toolbar button to insert ![User Asset](assets/img_p0_0.png).
  • Click any image in Read Mode to open it in the full-screen lightbox.

Code Blocks

Wrap multi-line code in triple backticks (```), with an optional language name:

```js
function greet(name) {
  return `Hello, ${name}`;
}
```

Mermaid Diagrams

Create diagrams using a fenced mermaid block (or click the Diagram button in the notes toolbar). Click any rendered diagram in Read Mode to zoom in the lightbox:

```mermaid
graph TD
    A[Read Page] --> B{Important?}
    B -->|Yes| C[Highlight & Note]
    B -->|No| D[Next Page]
```

Supported Mermaid types include flowcharts (graph TD/LR), sequenceDiagram, classDiagram, stateDiagram-v2, erDiagram, gantt, pie, and mindmap.

Safe HTML Elements

PDFNote uses standard CommonMark plus a sanitized HTML subset for extra formatting such as highlights, strikethrough, collapsible sections, and tables:

<mark>Highlighted text</mark>, <del>deleted</del>, <u>underlined</u>
H<sub>2</sub>O and x<sup>2</sup>

<details>
  <summary>Collapsible note</summary>
  Hidden details revealed on click.
</details>
